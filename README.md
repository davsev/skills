# skills

Agent skills for Claude Code. Run `./install.sh` to symlink skills into `~/.claude/skills/`.

## Skills

| Skill | Description |
|-------|-------------|
| `auto-continue` | Survive usage limits with checkpoint + resume |
| `value` | Spec-driven development focused on user value |

### Value framework

```bash
./install.sh                              # link skill
./value/install-commands.sh               # link /value:* slash commands
```
